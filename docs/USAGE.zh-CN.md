# OpenClaw Local Console 使用说明

语言: [English](USAGE.md) | **中文**

## 开始前

1. 确认终端里可以直接使用 `python`。
2. 确认本机已安装 Node.js。
3. 确认本机已经安装 OpenClaw，或者准备通过控制台完成初始化。
4. 如果你的网络访问 GitHub 或模型接口需要代理，请先在本机环境里配置好自己的代理。

## 推荐启动方式

### 第一次使用

运行：

```bat
setup_local_console.bat
```

这个脚本会：

- 检查 Python 是否可用
- 运行编码检查
- 提醒你本地依赖是否齐全
- 启动控制台

### 后续日常使用

运行：

```bat
run_console.bat
```

## 控制台主要区域

### 概览

这里适合快速查看：

- 当前服务状态
- 当前激活的 Profile
- 基础环境是否就绪
- 下一步快捷动作

### Provider 与模型

这里可以：

- 创建或修改 provider profile
- 保存密钥
- 切换模型
- 做最小连通性测试

### 通道与密钥

这里可以：

- 查看通道是否就绪
- 修改连接设置
- 管理通道
- 管理密钥

### Token 用量

这里可以：

- 切换模型
- 查看最近一段时间的使用量
- 比较短期趋势

### 工作区

这里可以：

- 编辑核心 Markdown 文件
- 查看本地和在线 skill
- 安装和卸载 skill
- 谨慎查看维护相关动作

## 安全提醒

- 维护类动作执行前要认真确认范围。
- 重置和卸载流程已经刻意加了保护门槛。
- 这个控制台会直接操作你本机上的 OpenClaw 本地状态，不建议在不理解后果的情况下随意执行高风险动作。
